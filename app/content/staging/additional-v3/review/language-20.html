1. lan-a1-004 — A

The librarian gave Ava and I a tour.

The verb gave needs object pronouns: Ava and me. I is correct in the subject of the other sentence.

Tip: Check each complete sentence. Choose No error only when all three sentences follow standard written American English.

2. lan-a1-013 — B

After packing the instruments, the bus was ready to leave.

The introductory phrase makes the bus the packer. Name the people: After packing the instruments, the players boarded the bus.

Tip: Check each complete sentence. Choose No error only when all three sentences follow standard written American English.

3. lan-a1-017 — C

The band was ready however, the curtain remained closed.

However is not a coordinating conjunction. Use The band was ready; however, the curtain remained closed.

Tip: Check each complete sentence. Choose No error only when all three sentences follow standard written American English.

4. lan-a1-029 — C

We visited the harbor; and watched the boats.

The second part has no subject and is not an independent clause; omit the semicolon.

Tip: Check each complete sentence. Choose No error only when all three sentences follow standard written American English.

5. lan-a1-048 — B

A number of volunteers was waiting outside.

A number of meaning several takes the plural verb were. The number of is singular and correctly takes was.

Tip: Check each complete sentence. Choose No error only when all three sentences follow standard written American English.

No error.
